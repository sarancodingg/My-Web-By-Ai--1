# Forever With You 🩵 | เว็บสื่อรัก & บอกความในใจถึงขนมหวาน

เว็บไซต์บอกความในใจสุดพิเศษที่สร้างด้วยความรักและเทคโนโลยีเว็บสมัยใหม่ ออกแบบในสไตล์ **Sky Blue / Pastel Azure & Glassmorphism** พร้อมระบบ Interactive แบบจัดเต็ม 💌

---

## ✨ ฟีเจอร์เด่น (Key Features)

- 💌 **3D Interactive Love Envelope**: ซองจดหมายเปิดอ่านแบบ 3 มิติ พร้อมตราประทับขี้ผึ้งสีฟ้าสว่าง
- 🎵 **Romantic Music Box (Web Audio API)**: ระบบเพลงกล่องดนตรีบรรเลงและเสียงเอฟเฟกต์ในตัว ทำงานได้ทันทีโดยไม่ต้องโหลดไฟล์ MP3
- ☁️ **Canvas Particle Engine**: ละอองและหัวใจสีฟ้าลอยละล่อง พร้อมเอฟเฟกต์ประกายดาวตามรอยเมาส์และนิ้วสัมผัส
- 📸 **Polaroid Memories**: กรอบภาพความทรงจำ 3 มิติที่ขยับตามมุมมอง (พร้อมภาพถ่ายจริง)
- 🎯 **Cute-O-Meter**: ระบบตรวจวัดความน่ารักของขนมหวานแบบหลอดแตกทะลุ 999%
- ⏳ **Days Counter**: นาฬิกานับเวลาตั้งแต่ 15 พฤศจิกายน 2566 เวลา 21:00 น. แบบ Real-time
- 🔮 **Fortune Love Cards**: การ์ดสุ่มคำพูดหวานๆ และมุกจีบน่ารักๆ
- 💍 **The Runaway Button**: ปุ่ม "อยู่ด้วยกันนานๆนะ" พร้อมปุ่มวิ่งหนีสุดกวน
- 📜 **Official Love Certificate**: ใบรับรองความรักอย่างเป็นทางการพร้อมพลุกระดาษเฉลิมฉลอง
- ⚙️ **Personalization & URL Sharing Engine**: ระบบสร้างลิงก์สำหรับส่งต่อให้เปิดดูในโทรศัพท์ได้ทันที

## 🚀 วิธีเปิดใช้งาน (How to Run)

สามารถดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ได้ทันที หรือรันผ่าน Local Server:

```bash
# รันผ่าน Python
python -m http.server 3000

# หรือรันผ่าน Node.js
npx serve .
```

เข้าชมผ่าน `http://localhost:3000`

---

## 🌐 เปิดให้ใช้งานออนไลน์ฟรีผ่าน GitHub Pages
1. เข้าไปที่ **Repository Settings** บน GitHub
2. ไปที่เมนู **Pages** (แถบด้านซ้าย)
3. ภายใต้ **Build and deployment > Branch** ให้เลือก `main` และ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ออนไลน์ (เช่น `https://sarancodingg.github.io/My-Web-By-Ai--1/`) ที่ส่งให้ขนมหวานเปิดดูได้ทุกที่ ทุกเวลา! 🩵
